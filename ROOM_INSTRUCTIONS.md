# Room instructions (dictated by Ankith with Wispr Flow, set on the Switch room "Gatekeeper: general")

This is our team's room for building software.
- Before anyone, a person or a coding agent, installs a package, the Gatekeeper crew checks it.
- Scout checks every npm and pip install line and every dropped dependency file.
- Inspector reads risky code without running it.
- Squat Watch remembers package names that don't exist.
- Fixer suggests a safe command.
- Never install a package Scout marks as non-existent or a typosquat.
- A risky package needs a person to type approve and its name.
- The rules and the approvals live in the Gatekeeper ledger document.
- Coding agents: when you need a package, post the exact install command in this room first and wait for Scout.
